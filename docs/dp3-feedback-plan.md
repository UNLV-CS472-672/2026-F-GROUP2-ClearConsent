## 3. Evaluation of the integrated system

Freeze the tested commit, deployment URL/revision, date, browser/device, relevant feature flags, and whether analysis was live or mocked. Record owner/team pilots separately from independent participants. Give each participant the same core tasks:

1. Submit the same policy text or URL and identify the main practices with supporting excerpts.
2. Set a privacy preference, inspect its effect on the result, and explain any confusing indicator.
3. Find the saved result in History and reopen it after leaving the result page.
4. Describe anything misleading, missing, slow, or hard to understand, then suggest an improvement.

Observe task completion, misclicks, errors, time, and comments as a **user feedback study**, not a factual quiz. Use participant codes and consent; do not put private inputs or identities in GitHub. Report counts and denominators, severity, and evidence for findings; link agreed changes to issues/PRs and retest where feasible. Earlier fixed-sample navigation feedback remains prototype evidence. The owner-observed Chewy run is a live pilot, not an independent-participant result.
